# 八大报刊每日获取

八大党报电子报**每日全量**抓取工具：按「报纸 + 日期 + 版面」分类落地 CSV，适合作为新闻文本研究的语料采集层。

覆盖报纸（均以官方数字报为准）：

| 报纸 | 数据来源 |
|---|---|
| 人民日报 | paper.people.com.cn |
| 光明日报 | epaper.gmw.cn |
| 中国青年报 | zqb.cyol.com |
| 经济日报 | paper.ce.cn |
| 解放日报 | jfdaily.com（JSON 接口） |
| 新华日报 | xh.xhby.net |
| 解放军报 | 81.cn（index.json） |
| 工人日报 | workercn.cn |

## 安装

```bash
pip install -r requirements.txt
```

Python 3.8+。

## 用法

```bash
python 爬虫脚本/八大报纸_爬虫.py                       # 抓今天全部八报 + 当日汇总
python 爬虫脚本/八大报纸_爬虫.py --papers 人民日报,经济日报
python 爬虫脚本/八大报纸_爬虫.py --date 2026-10-27
python 爬虫脚本/八大报纸_爬虫.py --no-body             # 仅标题与版面（快）
python 爬虫脚本/八大报纸_爬虫.py --no-combine          # 只写分表
python 爬虫脚本/八大报纸_爬虫.py --jobs 8              # 正文并发数
python 爬虫脚本/八大报纸_爬虫.py --combine-only        # 仅重建当日汇总
```

## 输出结构

```
数据/八大报纸/
  人民日报/2026/2026-10-27.csv     # 每报每日一表
  光明日报/2026/2026-10-27.csv
  ...
  当日汇总/2026-10-27.csv          # 八报合并表（默认自动生成）
  运行日志.txt                     # 1MB 轮转，保留 2 份
```

字段：`报纸 / 发布日期 / 版面序号 / 版面名称 / 标题 / 副标题 / 作者 / 来源 / 摘要 / 正文 / 字数 / 链接 / 采集时间`。

## 每日自动更新

Windows 计划任务「八大报刊每日获取」每天 07:30 运行：

```powershell
Get-ScheduledTask -TaskName 八大报刊每日获取 | Get-ScheduledTaskInfo
Start-ScheduledTask -TaskName 八大报刊每日获取        # 手动触发
```

任务设置了「错过时间后尽快补跑」与「仅在联网时运行」，开机/联网后会自动补齐当天数据。

## 说明

- 五份报纸共用「PC 数字报」版式：版面目录 → 文章链接 → 正文；解放日报与解放军报走 JSON 数据接口；工人日报按版面页顺序翻页。
- 采集幂等：同一链接自动合并，内容无变化时不重写文件；正文抓取成功的记录覆盖旧字段。
- 磁盘写入优化：当日汇总默认生成但只在内容变化时落盘；分表内容无变化不重写；日志按 1MB 轮转；运行不产生 `__pycache__`。
- 单报失败不影响其余报纸，异常写入 `数据/八大报纸/运行日志.txt`。
- 仅抓取公开可见的电子报内容，请遵守各报网站条款，数据仅用于个人研究。
